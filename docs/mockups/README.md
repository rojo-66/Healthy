# Mockup approvati

Questi file sono le schermate progettate e approvate. Sono **riferimento visivo**, non codice da copiare:
usano un formato di prototipazione (`.dc.html`, con un runtime `support.js` che qui non c'è), quindi non si aprono da soli nel browser.

Da leggere per ricavare: struttura della schermata, testi, colori, dimensioni, stati e animazioni (classi CSS `.tap`, `.drop`, `.sheet`, `.rise`…).
La logica di esempio è nel blocco `<script type="text/x-dc">` in fondo a ogni file (`renderVals()`): dati finti (nessun dato personale: il repo è pubblico).

| `Main.dc.html` | Oggi / Home | SPEC § 5.1 |
| `Allena.dc.html` | Allena (schede e storico) | § 5.2 |
